# Fonts

Self-hosted web fonts. They're the unmodified Latin variable subsets published by Fontsource, so the original family names are kept.

| File | Family | Use | Source | Licence |
|---|---|---|---|---|
| `plus-jakarta-sans-latin-wght.woff2` | Plus Jakarta Sans (variable, weights 200–800) | The player app since v3: every role (`--serif`, `--caps`, `--mono`, `--num`) | `@fontsource-variable/plus-jakarta-sans@5.2.8` | SIL OFL 1.1, see `PlusJakartaSans-OFL.txt` (no Reserved Font Name) |
| `nunito-latin-wght.woff2`, `nunito-latin-wght-italic.woff2` | Nunito (variable, weights 200–1000) | The admin portal (`admin.html`): body text, labels, numbers | `@fontsource-variable/nunito@5.2.7` | SIL OFL 1.1, see `Nunito-OFL.txt` |
| `fredoka-latin-wght.woff2` | Fredoka (variable, weights 300–700) | The admin portal (`admin.html`): headings | `@fontsource-variable/fredoka@5.2.10` | SIL OFL 1.1, see `Fredoka-OFL.txt` |

Glyphs outside the Latin subset (→ ✓ ✦ ⌫ ★ ≤) fall back to the system font.
